# Processed Data Directory

## Overview
This directory stores the cleaned, standardized, and feature-engineered dataset generated by the pipeline.

- **Primary Processed File**: `admissions_cleaned.csv`
- **Record Count**: 54,967 lines (1 header line + 54,966 cleaned unique admission records)
- **Transformations Applied**:
  1. Exact duplicate rows removed (534 duplicates eliminated).
  2. Technical surrogate key `admission_record_id` (1 to 54,966) assigned as the primary identifier.
  3. Patient names converted to Title Case via `INITCAP` standardization.
  4. String attributes trimmed of extraneous whitespace.
  5. Derived `length_of_stay_days` computed from calendar difference (`discharge_date - date_of_admission`).
  6. Derived `is_negative_billing` boolean flag assigned for accounting adjustment isolation.
  7. Derived `age_group` demographic classification assigned (`< 18`, `18 - 35`, `36 - 50`, `51 - 65`, `65+`).
  8. Numerical precision standard: `billing_amount` rounded to 2 decimal places.

## Generation
This file can be regenerated idempotently at any time by executing:
```powershell
python scripts/verify_and_compute_metrics.py
```
Or within PostgreSQL by running `sql/04_cleaning.sql`.
